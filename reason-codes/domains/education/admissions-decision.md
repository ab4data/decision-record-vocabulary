# University admissions decision

**Sector:** education

| `code` | `class` | Use when |
|---|---|---|
| `meets_entry_requirements` | `conformed` | Rank and prerequisites satisfied |
| `qualifications_unverified` | `evidence_insufficient` | Transcripts or credentials not verified |
| `credential_inconsistent` | `evidence_contradicts` | Documents conflict with the issuing institution record |
| `prerequisite_not_met` | `rule_conflict` | A required subject or score is absent |
| `quota_filled` | `capacity_or_cost` | Qualified, places exhausted |
| `special_entry_pathway` | `risk_elevated` | Admitted on assessed potential outside the standard rank |
| `credential_authority` | `third_party` | Recognition set by an external assessing body |
| `other` | `other` | Free text required |
