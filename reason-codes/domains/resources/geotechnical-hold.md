# Geotechnical hold point release

**Sector:** resources

| `code` | `class` | Use when |
|---|---|---|
| `released_to_mine` | `conformed` | Conditions sit within the ground control plan |
| `monitoring_data_gap` | `evidence_insufficient` | Instrumentation offline or not yet installed |
| `movement_vs_model` | `evidence_contradicts` | Measured movement disagrees with the model |
| `trigger_level_exceeded` | `rule_conflict` | A defined trigger or action level was crossed |
| `slope_risk_judgement` | `risk_elevated` | Held on assessed slope risk rather than a trigger |
| `production_impact` | `capacity_or_cost` | Release weighed against production loss |
| `inspection_window` | `timing` | Held until the next inspection window |
| `regulator_direction` | `third_party` | Directed by the mines inspectorate |
| `other` | `other` | Free text required |
