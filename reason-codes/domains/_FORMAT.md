# File format

Each domain file is a table with three columns:

| `code` | `class` | Use when |
|---|---|---|

- **`code`** — the value the domain actually stores. Local, and it should stay local.
- **`class`** — one of the shared classes in [`../ANALYSIS.md`](../ANALYSIS.md). **This is the conformed part.**
- **Use when** — the sentence a practitioner reads to pick it.

The point of the `class` column is that nobody has to adopt anybody else's codes. Two teams keep their own words and still answer the same question across both.
