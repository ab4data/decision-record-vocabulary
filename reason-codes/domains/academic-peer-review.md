# Academic peer review

| `code` | `class` | Use when |
|---|---|---|
| `accept_as_sound` | conformed | Method and conclusions supported |
| `method_underspecified` | evidence_insufficient | Cannot assess the work as described |
| `conclusions_overreach` | evidence_contradicts | Claims exceed what the results support |
| `analysis_error` | rule_conflict | A specific statistical or logical fault |
| `out_of_scope_journal` | out_of_scope | Sound, wrong venue |
| `novelty_insufficient` | rule_conflict | Correct, and does not advance the field |
| `ethics_or_data_availability` | rule_conflict | Approval or data statement missing |
| `reviewer_conflict` | authority_exceeded | Declined and returned to the editor |
| `other` | other | Free text required |
