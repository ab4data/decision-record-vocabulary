# Drill target selection

**Sector:** resources

| `code` | `class` | Use when |
|---|---|---|
| `target_approved` | `conformed` | Meets the ranking criteria for the programme |
| `survey_coverage_incomplete` | `evidence_insufficient` | Geophysical or geochemical coverage too sparse to rank |
| `models_disagree` | `evidence_contradicts` | Competing interpretations of the same dataset |
| `tenement_condition` | `rule_conflict` | A licence or permit condition prevents it |
| `prospectivity_judgement` | `risk_elevated` | Ranked on interpretation rather than a threshold |
| `rig_availability` | `capacity_or_cost` | Limited by rig days or programme budget |
| `access_window` | `timing` | Access closed within the planned window |
| `landholder_agreement` | `third_party` | Access set by a landholder or traditional owner agreement |
| `other` | `other` | Free text required |
