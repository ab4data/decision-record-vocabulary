# Biosecurity intervention decision

**Sector:** environment

| `code` | `class` | Use when |
|---|---|---|
| `cleared_no_intervention` | `conformed` | Assessed as low risk, released |
| `declaration_unclear` | `evidence_insufficient` | Import declaration insufficient to assess |
| `inspection_vs_declaration` | `evidence_contradicts` | Physical inspection differs from the declaration |
| `prohibited_commodity` | `rule_conflict` | Commodity not permitted from that origin |
| `pest_detection_risk` | `risk_elevated` | Escalated on an interception pattern |
| `treatment_capacity` | `capacity_or_cost` | Held pending treatment availability |
| `exporting_country_certification` | `third_party` | Reliance on the exporting authority certificate |
| `other` | `other` | Free text required |
