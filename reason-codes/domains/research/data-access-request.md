# Research data access request

**Sector:** research

| `code` | `class` | Use when |
|---|---|---|
| `approved_under_agreement` | `conformed` | Purpose and safeguards meet the access conditions |
| `purpose_unclear` | `evidence_insufficient` | Research question not specified well enough to assess |
| `request_exceeds_purpose` | `evidence_contradicts` | Variables requested exceed the stated purpose |
| `reidentification_risk` | `risk_elevated` | Refused or reduced on disclosure risk |
| `consent_scope` | `rule_conflict` | Original consent does not cover the use |
| `custodian_refusal` | `third_party` | Data custodian declined |
| `secure_environment_capacity` | `capacity_or_cost` | Approved in principle, no analysis environment available |
| `other` | `other` | Free text required |
