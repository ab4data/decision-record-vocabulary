# Infection control response

**Sector:** health

| `code` | `class` | Use when |
|---|---|---|
| `standard_precautions` | `conformed` | Managed under routine precautions |
| `typing_pending` | `evidence_insufficient` | Organism not yet characterised |
| `epi_link_unconfirmed` | `evidence_contradicts` | Suspected link between cases not supported |
| `outbreak_threshold_met` | `rule_conflict` | Case count triggered the outbreak definition |
| `transmission_risk_high` | `risk_elevated` | Response escalated on setting or population |
| `isolation_capacity` | `capacity_or_cost` | Response shaped by available single rooms |
| `public_health_directed` | `third_party` | Action set by the external authority |
| `other` | `other` | Free text required |
