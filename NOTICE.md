# Why CC0

A shared vocabulary is worth something only if anyone can adopt it **without asking, without attribution obligations, and without checking whether their licence is compatible with someone else's.**

Attribution is welcome, and every source this draws on is named in [CLAIMS.md](CLAIMS.md). But *requiring* attribution would put friction in exactly the place this proposal needs none.

So the schema, the reason-code lists and the prose are dedicated to the public domain under [CC0 1.0](LICENSE). **Take them, change them, ship them, rename them. No permission needed.**
