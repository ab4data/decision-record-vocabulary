# Content moderation

⭐ **The only list here with a real-world counterpart at scale.** The EU transparency database carries sixteen violation categories and seventy keyword specifications, and still needs two "other" routes. Treat that as the realistic ceiling on how far a list can be refined.

| `reason_code` | Use when |
|---|---|
| `policy_breach_clear` | Unambiguously against a published rule |
| `policy_breach_contextual` | Against a rule once context is taken into account |
| `legal_requirement` | Required by law or a valid order |
| `rights_complaint_upheld` | A complaint from a rights holder was accepted |
| `no_breach_found` | Reported, assessed, and left in place |
| `insufficient_context` | Could not be judged on the material available |
| `escalated_specialist` | Beyond the reviewer's authority |
| `other` | Free text required, and watch this rate |
