# Grant assessment

**Sector:** government

| `code` | `class` | Use when |
|---|---|---|
| `meets_all_criteria` | `conformed` | Scored above threshold on every criterion |
| `application_incomplete` | `evidence_insufficient` | Required attachments or budget detail missing |
| `budget_unsupported` | `evidence_contradicts` | Costings conflict with the described activity |
| `ineligible_applicant` | `out_of_scope` | Entity type, location or sector not eligible |
| `below_merit_threshold` | `rule_conflict` | Scored, but under the cut |
| `deliverability_concern` | `risk_elevated` | Capability or track record drove the decision |
| `funds_exhausted` | `capacity_or_cost` | Merit sufficient, budget was not |
| `conflict_of_interest` | `authority_exceeded` | Assessor stood aside, decided elsewhere |
| `other` | `other` | Free text required |
