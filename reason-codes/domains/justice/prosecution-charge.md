# Prosecution charge decision

**Sector:** justice

| `code` | `class` | Use when |
|---|---|---|
| `prima_facie_and_public_interest` | `conformed` | Both limbs of the test satisfied |
| `evidence_gaps` | `evidence_insufficient` | Brief incomplete or key statements missing |
| `witness_accounts_conflict` | `evidence_contradicts` | Material inconsistency between witnesses |
| `no_reasonable_prospect` | `rule_conflict` | Test not met on the available evidence |
| `public_interest_against` | `risk_elevated` | Proceeding assessed as not in the public interest |
| `diversion_available` | `third_party` | Matter directed to a diversionary scheme |
| `limitation_expired` | `timing` | Outside the statutory time limit |
| `other` | `other` | Free text required |
