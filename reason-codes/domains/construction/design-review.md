# Design review decision

**Sector:** construction

| `code` | `class` | Use when |
|---|---|---|
| `approved_as_submitted` | `conformed` | The design meets the brief and the standards cited |
| `calculation_not_provided` | `evidence_insufficient` | Supporting structural or services calculation missing |
| `drawings_conflict` | `evidence_contradicts` | Architectural and services drawings disagree |
| `code_non_compliance` | `rule_conflict` | A specific clause of the building code is not met |
| `buildability_risk` | `risk_elevated` | Decided on constructability rather than a clause |
| `cost_plan_exceeded` | `capacity_or_cost` | The design exceeds the cost plan |
| `long_lead_item` | `timing` | The selection would miss the procurement window |
| `authority_condition` | `third_party` | Set by a consent condition or a utility provider |
| `other` | `other` | Free text required |
