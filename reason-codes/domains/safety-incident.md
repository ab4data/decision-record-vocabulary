# Safety incident classification

| `code` | `class` | Use when |
|---|---|---|
| `classified_to_matrix` | conformed | Consequence and likelihood scored to the matrix |
| `details_unavailable` | evidence_insufficient | Classified before the investigation closed |
| `report_conflicts` | evidence_contradicts | Worker account differs from site evidence |
| `potential_severity_uplift` | risk_elevated | Rated on what could have happened |
| `notifiable_to_regulator` | rule_conflict | Statutory notification threshold met |
| `contractor_controlled` | third_party | Activity under another party's control |
| `recurrence_pattern` | risk_elevated | Rated higher because it has happened before |
| `investigation_escalated` | authority_exceeded | Beyond the supervisor's authority |
| `other` | other | Free text required |
