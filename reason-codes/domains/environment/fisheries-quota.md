# Fisheries quota decision

**Sector:** environment

| `code` | `class` | Use when |
|---|---|---|
| `within_allocation` | `conformed` | Catch within the allocated quota |
| `logbook_incomplete` | `evidence_insufficient` | Catch records not submitted |
| `logbook_vs_landing` | `evidence_contradicts` | Reported catch differs from landing records |
| `size_or_species_rule` | `rule_conflict` | Protected species or undersize take |
| `stock_assessment_decline` | `risk_elevated` | Allocation reduced on stock status |
| `monitoring_coverage` | `capacity_or_cost` | Observer coverage limited verification |
| `interjurisdictional` | `third_party` | Shared stock managed with another jurisdiction |
| `other` | `other` | Free text required |
