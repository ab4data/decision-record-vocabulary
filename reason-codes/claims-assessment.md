# Claims assessment

| `reason_code` | Use when |
|---|---|
| `within_policy` | The claim met the policy terms with no complication |
| `documentation_incomplete` | Required evidence was missing or unreadable |
| `valuation_disputed` | The amount claimed did not match the assessed value |
| `coverage_excluded` | The event falls outside the cover |
| `timing_outside_terms` | Notification or incident date falls outside the window |
| `suspected_misstatement` | The account given conflicts with the evidence |
| `referred_specialist` | Beyond the assessor's authority or expertise |
| `other` | Free text required, and watch this rate |
