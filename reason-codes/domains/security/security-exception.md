# Security policy exception

**Sector:** security

| `code` | `class` | Use when |
|---|---|---|
| `no_exception_needed` | `conformed` | Request met policy without an exception |
| `justification_insufficient` | `evidence_insufficient` | Business case not documented |
| `control_claim_unverified` | `evidence_contradicts` | Claimed compensating control not evidenced |
| `policy_breach_accepted` | `rule_conflict` | Granted against a specific control, with conditions |
| `residual_risk_too_high` | `risk_elevated` | Refused on assessed residual risk |
| `time_limited_exception` | `timing` | Granted only until a fixed date |
| `risk_owner_accepted` | `authority_exceeded` | Accepted by a named executive risk owner |
| `other` | `other` | Free text required |
