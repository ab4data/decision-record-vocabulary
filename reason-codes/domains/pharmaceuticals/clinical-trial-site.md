# Clinical trial site selection

**Sector:** pharmaceuticals

| `code` | `class` | Use when |
|---|---|---|
| `site_activated` | `conformed` | Meets the feasibility and quality criteria |
| `enrolment_history_unavailable` | `evidence_insufficient` | No recruitment record for the indication |
| `feasibility_vs_actuals` | `evidence_contradicts` | Stated capability conflicts with prior performance |
| `gcp_finding_open` | `rule_conflict` | An inspection finding remains unresolved |
| `population_not_represented` | `risk_elevated` | The site would not reach the intended population |
| `activation_cost` | `capacity_or_cost` | Start-up cost exceeds the value of the slot |
| `ethics_approval_pending` | `timing` | Approval not in place within the window |
| `sponsor_direction` | `third_party` | Decided by the sponsor |
| `other` | `other` | Free text required |
