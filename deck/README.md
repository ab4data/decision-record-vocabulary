# The talk

Two self-contained HTML files. Open either in a browser; arrow keys, space, Home and End navigate. **No build step, no dependencies, no network calls** beyond a Google Fonts stylesheet.

| File | |
|---|---|
| [`the-second-wave-animated.html`](the-second-wave-animated.html) | The presented version, with seven animated diagrams |
| [`the-second-wave.html`](the-second-wave.html) | The same content with the animated diagrams removed |

Speaker notes are in `<aside>` elements in the source — hidden on screen, readable in the file.

`prefers-reduced-motion` is honoured: with it switched on, every diagram renders in its final state instead of moving.

**First given at the Hunter Data Analytics meetup, Newcastle, 29 October 2026.**
