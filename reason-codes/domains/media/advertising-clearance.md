# Advertising clearance decision

**Sector:** media

| `code` | `class` | Use when |
|---|---|---|
| `cleared_as_submitted` | `conformed` | Meets the advertising code as submitted |
| `substantiation_missing` | `evidence_insufficient` | Claim substantiation not provided |
| `claim_vs_evidence` | `evidence_contradicts` | Substantiation does not support the claim made |
| `code_breach` | `rule_conflict` | Breaches a specific provision |
| `audience_sensitivity` | `risk_elevated` | Restricted by placement or time |
| `regulator_precedent` | `third_party` | Determined by a prior ruling |
| `campaign_timing` | `timing` | Clearance shaped by the flight date |
| `other` | `other` | Free text required |
