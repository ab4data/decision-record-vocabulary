# Service desk triage

| `reason_code` | Use when |
|---|---|
| `known_issue` | Matches a recorded problem with a known workaround |
| `user_error` | Resolved by guidance rather than by change |
| `access_rights` | A permissions or entitlement matter |
| `data_quality` | The system behaved correctly on incorrect data |
| `defect_suspected` | Reproducible and unexplained; escalated |
| `third_party` | Cause sits outside systems we control |
| `insufficient_detail` | Could not be progressed as reported |
| `other` | Free text required, and watch this rate |
