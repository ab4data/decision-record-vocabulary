# Freedom of information request

**Sector:** government

| `code` | `class` | Use when |
|---|---|---|
| `released_in_full` | `conformed` | Documents released without redaction |
| `scope_unclear` | `evidence_insufficient` | Request too vague to identify documents |
| `no_documents_held` | `out_of_scope` | Search complete, nothing within scope exists |
| `exemption_applied` | `rule_conflict` | A statutory exemption covers some or all |
| `third_party_consultation` | `third_party` | Outcome depends on a consulted party view |
| `personal_privacy` | `rule_conflict` | Release would disclose personal information |
| `processing_burden` | `capacity_or_cost` | Volume made the request impracticable as framed |
| `statutory_period` | `timing` | Decision shaped by the statutory clock |
| `other` | `other` | Free text required |
