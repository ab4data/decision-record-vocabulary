# Code review

| `reason_code` | Use when |
|---|---|
| `meets_standard` | Approved with no substantive change requested |
| `correctness_risk` | A defect or an unhandled case |
| `test_coverage` | The change is plausible but untested |
| `readability` | Correct, but the next person will struggle |
| `scope_creep` | Does more than the ticket asked |
| `security_concern` | Introduces or fails to close an exposure |
| `architecture_mismatch` | Conflicts with an existing decision — cite it in `basis_refs` |
| `other` | Free text required, and watch this rate |
